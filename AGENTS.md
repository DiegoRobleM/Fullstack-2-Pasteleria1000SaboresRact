# Instrucciones para el asistente

## Ubicación de cambios de código

Cuando indiques al usuario que añada o reemplace código en una parte concreta, especifica el archivo y la línea aproximada. Incluye también un fragmento de referencia para ubicar el cambio si la numeración de líneas ha variado.

## Gestor de paquetes

En este proyecto, utiliza npm para instalar dependencias y ejecutar los scripts. Tanto los comandos que ejecutes como las instrucciones que des al usuario deben usar npm: `npm install`, `npm run dev`, `npm run build`, `npm run preview` y `npm test`.
